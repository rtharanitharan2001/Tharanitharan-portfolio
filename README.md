# THARANITHARAN — THE SERIES

A responsive, interactive Netflix-inspired personal portfolio for Tharanitharan.

## Preview
Open `index.html` in a modern browser. The website works without a build process. Google Fonts requires an internet connection; local fallbacks are provided.

## Customize
- Email and phone links are set in `index.html`. Confirm the email spelling before publishing; LinkedIn is optional.
- Replace `assets/profile.jpg` to change the portrait.
- Edit `index.html` and the `episodes` array in `script.js` to update your story.
- Add a verified, updated resume PDF to the folder and link it from `index.html` once available. A resume download has intentionally not been added because an accurate resume file was not supplied.

## Publish
Upload this folder to a GitHub repository and enable GitHub Pages under Settings → Pages → Deploy from a branch (main / root). Alternatively, drag the folder into Netlify Drop.

This is an original implementation inspired by streaming-service visual conventions; it does not copy Netflix assets or code.
